## Running the code

- **Python** scripts target Python 3.10+ and use only the standard library. `MOD 7/turnin/mitigations.py` and `rss_breakdown.py` additionally use `numpy` if it is installed (the NumPy mitigation is skipped otherwise).
- **C** (`MOD 7/turnin/csort.c`) is compiled automatically by `mitigations.py` on first run via `cc -O2 -shared -fPIC`; a C compiler must be on `PATH`.
- **Go** (`MOD 7/assignment/gobench/`) — `go run .` inside that directory.
- **Java** (`MOD 6/Module Six Assignment/SampleFibonacci.java`) — `javac SampleFibonacci.java && java SampleFibonacci`.

Compiled binaries are not committed; they are rebuilt from source as above.
